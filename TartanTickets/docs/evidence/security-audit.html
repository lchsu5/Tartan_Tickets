RequirementStatusWhy
SEC-1PartlyNo passwords are stored, but the app does not authenticate users with CMU SSO.
SEC-2Not at allThe app does not create or expire user sessions.
SEC-3Fully (Vercel deployment)The live homepage and both API routes redirect HTTP to HTTPS and send HSTS via Vercel; local development still uses HTTP.

SEC-5Not at allClub-scoped authorization, access-denied handling for club resources, and attempt logging are not implemented.
SEC-6Not at allTickets and student-owned ticket lookup do not exist.
SEC-7PartlyThe demo accepts no card numbers, but it does not integrate Stripe-hosted Checkout.
SEC-8Not at allCheckout and charge calculation are not implemented.
SEC-9Not at allThere is no Stripe webhook endpoint, signature verification, or webhook logging.
SEC-10Not at allStripe events, ticket issuance, and duplicate-event handling are not implemented.
